# User flow MVP сервиса букшеринга

Источник: [idea.md](idea.md). Диаграмма описывает обмен книг за баллы. Подписочный прокат — следующий этап, его условия в исходном описании пока не определены.

```mermaid
flowchart TD
    Start([Пользователь открывает сервис]) --> Login[Вход через Яндекс ID]
    Login --> Home[Главная: каталог, рекомендации, баланс баллов]
    Home --> Browse[Просмотр каталога и рекомендаций]
    Home --> Give[Сдать книгу]
    Home --> Favorites[Понравившиеся книги]
    Favorites --> Card[Карточка книги]
    Browse --> Card
    Card --> Save[Добавить в понравившиеся]
    Save --> Favorites
    Card --> Available{Книга есть у сервиса?}

    Give --> Photo[Отправить фотографию книги]
    Photo --> Review[Ручная проверка и оценка в баллах]
    Review --> Offer[Посмотреть предложенную оценку]
    Offer --> Accept{Согласен с оценкой?}
    Accept -->|Нет| Cancel([Отказ от сдачи])
    Accept -->|Да| Method{Способ передачи книги}
    Method -->|Курьер| Courier[Передать книгу курьеру]
    Method -->|Постамат| Locker[Передать книгу через постамат]
    Courier --> Credit[Начисление баллов после передачи]
    Locker --> Credit
    Credit --> Home

    Available -->|Да| Enough{Достаточно баллов?}
    Enough -->|Нет| Need[Сдать книгу для получения баллов]
    Need --> Give
    Enough -->|Да| Order[Оформить заказ за баллы]
    Order --> Address[Указать адрес доставки]
    Address --> Spend[Подтвердить заказ и списать баллы]
    Spend --> Delivery[Курьерская доставка]
    Delivery --> Received([Книга получена])

    Available -->|Нет| Request[Оставить заявку на книгу]
    Request --> Purchase[Сервис приобретает книгу за свой счёт]
    Purchase --> Notify[Уведомление о доступности книги]
    Notify --> Card
```

## Допущения для связности сценария

- Вход показан до каталога; возможность просмотра без авторизации не описана.
- Пользователь может согласиться с оценкой или отказаться от сдачи.
- При недостатке баллов пользователь возвращается к сдаче книги; другие способы пополнения не описаны.
- Адрес, подтверждение заказа и момент списания баллов добавлены как предполагаемые шаги оформления.
- После покупки книги по заявке предполагается уведомление и обычный заказ за баллы. Исходное описание не уточняет, резервируется ли книга за заявителем.

## Переходы, требующие уточнения

- Отказ в приёмке книги и расхождение состояния с фотографией.
- Ошибка входа, отмена заказа, недоступность книги во время оформления и неудачная доставка.
- Срок выполнения заявки на отсутствующую книгу.
- Остаётся ли полученная книга у пользователя или должна быть возвращена.
