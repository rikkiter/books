Сервис букшеринга

Полноценная идея - это создать подписочный сервис проката бумажных книг с доставкой их на дом.

В рамках MVP, для набора аудитории планируется реализовать сервис обмена книг с курьерской доставкой.

Функционал MVP:
- Вход через Яндекс ID
- Каталог книг
- Система рекомендаций
- Сдача книг:
    - Пользователь отправляет фотографию книги, система оценивать её в определенное количество баллов, после передачи курьеру или в постамат баллы начисляются
    - Первое время думаю можно сделать ручную проверку фотографий книг, а потом привязать ML модель
- Получение книг:
    - Пользователь выбирает книгу, среди имеющихся у сервиса, которую он может заказать в обмен на полученные баллы
    - Если интересующей книги нет, пользователь может оставить заявку на неё и сервис приобретёт её за свой счёт
- Понравившиеся книги
